# Zoho People Leave/Time-Off Management — Feature Capability Reference

**Purpose**: Factual, own-words summary of Zoho People's Leave Service business rules and capability depth, for use as a functional-parity reference while building a Monolith-native Leave Management module (Next.js/Prisma). This is NOT a UI clone and contains no verbatim text, screenshots, or branding from Zoho.

**Research date**: 2026-08-14
**Scope**: Publicly available Zoho People Help/Administrator Guide, Employee Handbook, product pages, and API documentation only. Statutory/regulatory leave law research is explicitly out of scope (separate phase).
**Legend for "Monolith equivalent status"**: All rows are set to `TBD — see gap analysis` per instructions; a later phase fills this in against the existing codebase audit.
